This is a project for flight booking and airport management. It uses MongoDB for database and runs on Node. 

To run the project make sure Node and MongoDB dependencies are installed then import the database (Database_Json) into a MongoDB database named airport_managemnet. 
The collection name are given in the file name iself. (for airport_management.arrival_list.json, collection name is arrival_list) 

Finally run, "node Express.js" in your terminal
